# Terminal Portfolio Website

Personal resume site that looks like a terminal. Static files only — no build, no backend.

**Live:** [alfdav.github.io](https://alfdav.github.io/)

## Commands

`help` (`ls`, `dir`), `about`, `skills`, `experience`, `education`, `projects`, `certs` / `certifications`, `verify <name>`, `contact`, `clear`

Tab completes. Up/down walks history. Konami code is an easter egg.

## Edit

Resume content lives in `resume.js`. Serve with `python3 -m http.server` or open `index.html`.
